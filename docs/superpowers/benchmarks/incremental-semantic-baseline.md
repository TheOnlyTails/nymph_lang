Times below are Criterion point estimates (the middle value in its reported interval). `Median peak retained` is the 11th ordered value from 21 isolated measurements of the maximum increase in live allocated bytes during exactly one compiler operation, measured by the benchmark executable's counting global allocator across the compiler's Rayon workers. It is a separate statistic from Criterion's time estimate. `Source retained` is the deterministic fixture's owned key and source bytes. Generated bytes are the final bundled JavaScript size; checks generate zero bytes. Absolute values are informational. Future ratio gates must compare against fresh runs in the same process.

Phase counts use `P/G/R/C/L/E/B` for parse, graph, rewrite, check, lower, emit, and bundle. Every shape contains 17 reachable modules. “Unchanged” primes the same fixture before measuring a second invocation; the pre-Salsa API retains no compilation session, so its phase counts intentionally equal a fresh invocation.

Each sample resets the counter to the current live-byte level immediately before the compiler operation; fixture creation, cloning, priming, and mutation are untimed setup and excluded from both timing and peak deltas. Replacement cases always prime the original state, mutate it, then compile the post-replacement state.
