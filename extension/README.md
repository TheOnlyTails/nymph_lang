# Nymph

Published target-specific VSIX packages include the matching `nymph-lsp`
executable under `server/`; users do not need Rust, a compiler, or a separate
server installation. For extension development only, `nymph.server.path` may
be set to an absolute path to a locally built executable. Leaving it empty
always uses the self-contained bundled server.

Nymph is a general-purpose programming language, designed to be simple and easy to use.

> [!WARNING]
> Nymph is still in development. The syntax and features may change in future releases.
> Please report any bugs or issues you encounter on the [GitHub repository](https://github.com/theonlytails/nymph_lang/issues).
